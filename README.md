# Robotics Practice

Spatial AI 연구실 신입생을 위한 로보틱스 입문 가이드와 실습 자료를 모아 둔 저장소다.

## Interactive Demos (HTML)
별도 설치 없이 브라우저에서 바로 실행할 수 있다: https://alexjunholee.github.io/robotics-practice/

## Python Scripts
로컬 환경에서 직접 돌려 볼 수 있는 실습 스크립트다. 필요한 패키지 의존성은 각 스크립트 파일 상단의 주석을 참고한다.

## 자매 프로젝트 — ai-research-practice·research-notes·grad-notes

이 저장소는 Spatial AI·SLAM·컴퓨터 비전의 기술 본문과 실습 코드를 다룬다. 연구 방법론과 대학원 생활에 관한 안내는 아래 자매 가이드에서 이어진다.

- **[ai-research-practice](../ai-research-practice/)** — AI와 로봇 연구하기: 작업 환경, 실험 근거, 원고 작성, runtime 디버깅.
- **[research-notes](../research-notes/)** — 「연구노트」: 논문 읽기, 연구 질문, 글쓰기, 발표.
- **[grad-notes](../grad-notes/)** — 「대학원노트」: 결정, 관계, 자율성, 감정, 진로.
