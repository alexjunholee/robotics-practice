M-Estimator 비용 함수 비교

다양한 robust cost function의 비용(cost)과 가중치(weight) 함수를 비교합니다

outlier가 클 때 어떤 함수가 영향을 덜 받는지 관찰하라 — residual이 커질수록 weight가 0에 가까워지는 함수일수록 outlier에 강건(robust)하다.
L2 (Least Squares)
ρ(r) = r²
w(r) = 2
Huber
ρ(r) = r² if |r|≤δ, 2δ|r|-δ² otherwise
w(r) = 2 if |r|≤δ, 2δ/|r| otherwise
Cauchy (Lorentzian)
ρ(r) = c² ln(1 + (r/c)²)
w(r) = 2 / (1 + (r/c)²)
Geman-McClure
ρ(r) = r² / (c² + r²)
w(r) = 2c² / (c² + r²)²
